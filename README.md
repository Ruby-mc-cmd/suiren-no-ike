# [睡蓮の池](https://ruby-mc-cmd.github.io/suiren-no-ike/docs/)

Three.js (r170) で作った、日本庭園の小さな池です。鯉十二尾、睡蓮、アメンボ、オタマジャクシから育っていくアマガエル、そしてときどき飛んでくるアオサギがいます。画像ファイルも音声ファイルも使わず、HTML 1枚で動きます。

## 開き方

**https://ruby-mc-cmd.github.io/suiren-no-ike/** で動きます（GitHub Pages）。手元で見るなら `docs/index.html` をブラウザで開きます。どちらも three.js を CDN（jsdelivr）から読み込むので、ネット接続が必要です。

- **メニュー**：ふだんは隠れていて、画面の上端にカーソルを寄せると上から出てきます。スマホなどではタップすると数秒間出ます（いちばん上をタップしたときは、餌を落とさずにメニューだけ出します）
- **視点**：池（全体）／カエル（1匹を追う。押すたびに、カエルもオタマジャクシも番号の小さい順に次の一匹へ）／水面。追っている間は左下に、番号、何世代目か（最初のオタマジャクシが第1世代、その子が第2世代）、生まれてからの日数と時間、育ち具合、体長、おなかの具合が出ます。題名の下には、いま池にいるいちばん新しい世代が出ます
- **ズーム**：メニューのバーで、左に動かすと引き、右に動かすと寄ります。ホイールやピンチとも連動します
- **光**：朝・昼・夕・夜・現在。「夜」は月明かりと星、灯籠の火、ホタル、虫の声とフクロウ。「現在」は端末の時計に合わせて、夜明けから夜まで光がゆっくり移り変わります。睡蓮は朝と夕方には閉じぎみになり、夜は閉じます
- **音**：ボタンでオン・オフ、スライダーで音量
- **名札**：追っている一匹の名札（生まれてからの日数など）を出す・消す
- **リセット**：2回続けて押すと、池の生き物がオタマジャクシ40匹からやり直しになります（保存していた様子も消えます）
- 水面をタップすると、餌が一粒ずつ落ちます。メニューの「餌」で、水面に浮く鯉の餌と、底に沈むオタマジャクシの餌を切り替えます
- 池の生き物の様子はブラウザ（localStorage）に保存され、次に開くと続きから始まります。閉じている間は進みません

## 中身

| パス | 内容 |
| --- | --- |
| `src/main.js` | シーンのすべて（水・光・鯉・カエル・アメンボ・植物・音・UI） |
| `src/head.html` | 画面の文字、ボタン、説明パネル（「仕組み」）、CSS |

| `docs/index.html` | そのまま開ける完成版（GitHub Pages で公開しているページ） |

| `tests/*.js` | 挙動の回帰テスト（泳ぎ、植生、鯉の採食、カエルの狩り、12分の長時間実行、カエルの一生15分、アオサギ） |

## 主な仕組み

- **水面**：GPU で波動方程式を解き、波紋・反射・屈折・コースティクスを描きます。浮き葉の下の影や、アメンボの脚が水面につくるくぼみのレンズ影も含みます
- **鯉**：群れで泳ぎ、餌や浮草を食べます。速く泳ぐと水をかく音がします
- **カエル**：SDF のレイマーチで描いています。跳ぶ、泳ぐ、葉に上がる、鳴く、瞬きをします。アメンボを舌で捕ったり、飛びかかったりもします。同時に最大8匹（シェーダーをあらかじめ8匹分コンパイルしておき、使い回します）
- **カエルの一生**：池の中では1秒が1時間。最初はオタマジャクシ40匹だけです。卵は3日でふ化し、オタマジャクシは底の藻を食べて育ち、後ろ足、前足の順に生えて、26日ほどで睡蓮の葉に上がります。子ガエルはしっぽが縮んで消えるとアメンボを捕り始め、卵からおよそ50日（20分）で大人になります。藻はゆっくりしか戻らないので、飢え、共食い、鯉に食べられることで、カエルになれるのは一部だけです。大人のメスはオスと浅瀬へ泳いで行って卵を産みます。寿命は一匹ずつ違い、アメンボが捕れないと飢えても死にます。カエルもオタマジャクシも卵もいなくなると、新しい卵が現れます
- **アメンボ**：14〜34秒ごとに飛来し、最大4匹。2〜4分ほど水面にいて、また飛び去ります
- **アオサギ**：昼間、開いてから3〜5分ほどで最初に飛んできて、そのあとは6〜12分おきに来ます。岸や浅瀬に降り、首をS字に縮めて歩き、くちばしでオタマジャクシや葉の上のカエルを突きます。カエルは気づくと水に逃げたり、突かれる瞬間に跳んでかわしたりします。届く獲物がいなければ短く飛んで場所を変え、何匹か捕るかしばらくすると鳴いて飛び去ります。近くをタップすると驚いて飛び立ちます。夜は来ません。脚・首・翼は CPU で計算した曲線と骨に沿って頂点シェーダーで形を作っています
- **ホタル**：夜になると56匹が岸辺や水面の上を舞います。一匹ずつばらばらに、4秒ほどふわっと光っては消えます。水面にも映ります
- **植物**：睡蓮、ハス、ヒシ、浮草、水草、ガマ、ススキ、彼岸花、ツワブキ、サザンカ、シダ、枝垂れ柳、散り紅葉。風、とくに突風に揺れます
- **音**：Web Audio で合成しています。風、水、虫、鳥、カエルの声、着水、泳ぐ音など。カメラからの距離と左右の位置で聞こえ方が変わります

## ビルドとテスト

```sh
python3 build.py                     # src/ → dist/pond.html, docs/index.html

# テストには Playwright と、three.js のローカルコピーが必要
pip install playwright && playwright install chromium
curl -o three.module.min.js https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.min.js
python3 tests/run.py                 # tests/*.js をすべて実行し、結果を tests/out/ に保存
python3 test.py --script '[["step",30],["canvas","shots/a.png"]]'   # 30フレーム描いて撮影
```

ページは `window.__pond` にデバッグ用の API を出しています。`tick(n)`（描画なしで n フレーム進める）、`step(n)`（描画あり）、`cmd(name, ...)`（視点やテスト用の配置）、`dbg` / `dbg_str` / `dbg_veg` / `dbg_life`（内部状態）などです。カエルの挙動のテストは `cmd('testfrogs')` で一生の仕組みを止め、以前の大人のカエル5匹に置き換えてから動かします。`cmd('lifefresh')` でオタマジャクシ40匹からやり直します。

## よく触る値

- アメンボ：`STR_MAX`（同時に何匹まで。4より大きくすると、5匹目以降は影が出ません）、`strSpawnT`（最初の飛来までの秒数）、`updateStriders` の `rr(14, 34)`（飛来の間隔）、`strNew` の `stay: rr(110, 240)`（水面にいる秒数）
- カエル：`FROG_SCALE`、`FROG_MAX`（同時に何匹まで）、子ガエルが育つ上限の `maxSize`（`tadToFrog`）
- アオサギ：`heron.next`（最初に来るまでの秒数）、`heronGone` の `lr(360, 720)`（次に来るまで）、`herCanStand`（立てる場所：深さ、葉や石や草からの距離）、`herAware`（カエルが気づく・逃げる確率）、`herStrikeStart` / `herStrikeHit`（かわす・捕まる確率）
- カエルの一生：`LIFE`（ふ化、足、上陸、しっぽが消える、大人になるまでの時間）、藻の量 `algaeReset(0.18)` と戻る速さ（`updateTadpoles` の `0.0003`）、寿命 `life`（`tadToFrog`）、飢え `FROG_STARVE`
- カエルの狩り：`FROG_REACH`（舌の届く距離）、`frogHuntSit`（気づく距離、飛びかかる距離）、`fullT`（食べたあと満腹でいる秒数）
